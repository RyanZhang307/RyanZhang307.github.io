Chapter 07

连续信道容量

Channel Capacity: Continuous

高斯信道、信噪比、Shannon–Hartley 定理和固定范围信道。

7.1 Introduction / 引言#

Continuous channels transmit real-valued signals. Their capacity depends not on the number of discrete symbols but on constraints such as signal power, noise variance, bandwidth, and allowed input range.

连续信道传输实值信号。其容量不由离散符号数量决定，而取决于信号功率、噪声方差、带宽和允许输入范围等约束。

7.2 Channel Capacity / 信道容量#

For any channel,

对任意信道：

$$C=\max_{p(X)}I(X;Y).$$

For an additive channel (Y=X+\eta), with independent noise,

对加性信道 (Y=X+\eta)，若噪声独立：

$$I(X;Y)=h(Y)-h(Y\mid X)=h(Y)-h(\eta),$$ $$C=\max_{p(X)}[h(Y)-h(\eta)].$$

The noise distribution is fixed by the channel, so capacity is achieved by choosing an input distribution that maximises output entropy under the physical constraints.

噪声分布由信道固定，因此要达到容量，需要在物理约束下选择使输出熵最大的输入分布。

7.3 The Gaussian Channel / 高斯信道#

Let Gaussian noise have variance (\sigma_\eta^2=N) and input power, or variance, (\sigma_X^2=P). Gaussian input maximises output entropy because a Gaussian has maximum entropy at fixed variance.

设高斯噪声方差为 (\sigma_\eta^2=N)，输入功率或方差为 (\sigma_X^2=P)。固定方差下高斯分布熵最大，因此高斯输入使输出熵最大。

Since (Y=X+\eta),

由于 (Y=X+\eta)：

$$\sigma_Y^2=P+N,$$ $$h(\eta)=\frac12\log(2\pi eN),\qquad h(Y)=\frac12\log[2\pi e(P+N)].$$

Therefore the capacity per independent real-valued channel use is

因此，每次独立实值信道使用的容量为：

$$C=\frac12\log_2\left(1+\frac{P}{N}\right)\ \text{bits}.$$

For bandwidth (B), the Shannon-Hartley form is

对带宽 (B)，Shannon-Hartley 形式为：

$$C=B\log_2\left(1+\frac{P}{N}\right)\ \text{bits/s}.$$

At high signal-to-noise ratio, capacity grows only logarithmically: large increases in power yield modest increases in rate.

在高信噪比下，容量只按对数增长：大幅提高功率只能带来较有限的速率提升。

7.4 Error Rates of Noisy Channels / 有噪信道的误码率#

Even when rate (R<C), a short or poorly designed code may have substantial error probability. For Gaussian codewords, error occurs when noise moves an output across a decision boundary. Increasing separation between codewords reduces error but allows fewer codewords within a fixed power region.

即使速率 (R<C)，短码或设计不佳的编码仍可能具有较高错误概率。对高斯码字，当噪声把输出推过判决边界时就会发生错误。增大码字间距可以降低错误率，但在固定功率区域内能够容纳的码字也会减少。

For two equally likely scalar Gaussian signals separated by distance (d), the error probability is determined by the Gaussian tail beyond the midpoint and decreases rapidly with (d/\sigma_\eta).

对两个等概率、间距为 (d) 的标量高斯信号，错误概率由越过中点的高斯尾部决定，并随 (d/\sigma_\eta) 增大而快速下降。

Figure 7.2. Error probability depends on overlap between noisy output distributions, even when the source rate is below capacity.

图 7.2　即使信源速率低于容量，错误概率仍取决于含噪输出分布的重叠程度。

7.5 Using a Gaussian Channel / 高斯信道的使用#

Long codewords are vectors

长码字表示为向量：

$$\mathbf{x}=(x_1,\ldots,x_n),\qquad \mathbf{y}=\mathbf{x}+\boldsymbol{\eta}.$$

If capacity is (C) bits per component, an (n)-component vector can carry up to (nC) bits and distinguish approximately

若每个分量容量为 (C) 比特，(n) 维向量最多携带 (nC) 比特，并可区分约：

$$m=2^{nC}$$

messages. In high dimensions, noise vectors concentrate in a thin shell. Codewords can be placed so that their likely noise spheres barely overlap, explaining why long codes approach capacity with small error.

条消息。在高维空间中，噪声向量集中于一个薄壳。可以放置码字，使其高概率噪声球几乎不重叠，这说明长码为什么能以很小错误率接近容量。

图 7.3　信号空间中的高斯码字及其周围噪声区域。

7.6 Mutual Information and Correlation / 互信息与相关#

For jointly Gaussian scalar variables with correlation coefficient (\rho),

对相关系数为 (\rho) 的联合高斯标量变量：

$$I(X;Y)=-\frac12\log_2(1-\rho^2) =\frac12\log_2\frac1{1-\rho^2}.$$

Equivalently,

等价地：

$$|\rho|=\sqrt{1-2^{-2I(X;Y)}}.$$

Zero correlation implies zero mutual information only for special families such as jointly Gaussian variables. In general, nonlinear dependence can yield zero correlation but positive mutual information.

只有对联合高斯等特殊分布族，零相关才意味着零互信息。一般情况下，非线性依赖可能使相关系数为零而互信息仍为正。

图 7.4-7.5　高斯散点图和曲线展示相关强度与互信息的关系。

7.7 The Fixed Range Channel / 固定范围信道#

Some channels constrain amplitude to a fixed interval rather than average power. For a noiseless fixed-range channel, a uniform input maximises entropy. If the source density is non-uniform, an invertible encoding (x=g(s)) can reshape it into a uniform channel-input density.

有些信道限制的是固定幅度范围，而不是平均功率。对无噪固定范围信道，均匀输入使熵最大。如果信源密度非均匀，可以利用可逆编码 (x=g(s)) 把它变换为均匀的信道输入密度。

Probability conservation gives

概率守恒给出：

$$p_X(x)=\frac{p_S(s)}{|g'(s)|}.$$

Choosing (g'(s)\propto p_S(s)) produces constant (p_X(x)); the cumulative distribution function is therefore a natural companding transform.

选择 (g'(s)\propto p_S(s)) 可得到常数 (p_X(x))；因此累积分布函数是自然的压扩变换。

With noise, the optimal input need not be exactly uniform because encoding must balance output entropy against noise sensitivity.

存在噪声时，最优输入未必严格均匀，因为编码需要在输出熵与噪声敏感性之间权衡。

Figure 7.6. An encoding function maps Gaussian-distributed source values into an approximately uniform fixed-range input distribution.

图 7.6　编码函数把高斯分布的信源值映射为近似均匀的固定范围输入分布。

7.8 Summary / 小结#

Continuous-channel capacity is the maximum mutual information under physical constraints. Gaussian inputs achieve the power-constrained Gaussian-channel capacity, while uniform inputs are optimal for noiseless fixed-range channels. Long vector codes make reliable operation near capacity possible. For Gaussian variables, mutual information has a simple relationship to correlation, but mutual information captures more general dependence.

连续信道容量是在物理约束下能够达到的最大互信息。高斯输入达到功率受限高斯信道的容量，均匀输入则适用于无噪固定范围信道。长向量码使接近容量的可靠运行成为可能。对高斯变量，互信息与相关系数具有简单关系，但互信息能够描述更一般的依赖。
