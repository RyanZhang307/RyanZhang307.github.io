3.1 Introduction / 引言#

Most natural signals, like sounds and images, convey information in a relatively dilute form, so that a large amount of data contains a small amount of information. There are two reasons why information is so dilute in natural signals.

声音和图像等大多数自然信号都以相对稀疏的形式传递信息，因此大量数据中往往只包含少量信息。自然信号中的信息如此稀疏，主要有两个原因。

First, values that are close to each other tend to have similar values, for example in images, or to be related to each other, for example in English, so that different signal values partially duplicate the information they carry.

第一，彼此接近的取值往往相似，例如图像中的相邻像素；或者彼此相关，例如英语中的相邻字母。因此，不同信号值携带的信息会发生部分重复。

A second, more subtle, reason involves the distribution of values in a signal. The optimal distribution for a given communication channel depends on the constraints that apply. For example, if a channel has fixed lower and upper bounds then recoding an iid signal so that all of its values occur equally often, i.e. a uniform distribution, guarantees that each binary digit carries as much information as possible, i.e. one bit. Thus, for a channel with fixed bounds, the optimal distribution is uniform.

第二个原因更为微妙，与信号取值的分布有关。给定通信信道的最优分布取决于它所受到的约束。例如，如果信道具有固定的上下界，那么把独立同分布信号重新编码，使所有取值以相同频率出现，也就是形成均匀分布，就能保证每个二进制数字携带尽可能多的信息，即一比特。因此，对于取值范围固定的信道，最优分布是均匀分布。

Together, these considerations suggest that a signal can be conveyed through a communication channel most efficiently if (1) it is first transformed to a signal with independent values, and (2) the values of this transformed signal have a distribution which has been optimised for that particular channel.

综合上述两点，如果要让信号以最高效率通过通信信道传输，应当：（1）先把它转换成各取值彼此独立的信号；（2）使转换后信号的取值分布针对该信道得到优化。

Figure 3.1. The discrete noiseless channel. Data in the form of symbols from a source are encoded as codewords, for example binary numbers, before being transmitted as inputs through a communication channel. At the other end, a receiver decodes these codewords to recover the original message.

图 3.1　离散无噪信道。信源产生的符号数据先被编码为码字，例如二进制数，再作为输入通过通信信道传输。在另一端，接收器对这些码字进行解码，以恢复原始消息。

The source coding theorem is so called because it is really about the coding of messages before they are transmitted through a communication channel, as in Figure 3.1. It states that messages can be recoded as described above, but it does not state how such recoding can be achieved. However, once the theorem had been proved, researchers began to search for, and soon found, coding schemes that were close to the theoretical limits defined by Shannon.

之所以称为“信源编码定理”，是因为它真正讨论的是消息在通过通信信道传输之前如何编码，如图 3.1 所示。该定理说明消息可以按上述方式重新编码，却没有说明具体如何实现。定理得到证明后，研究人员开始寻找编码方案，并很快发现了接近香农理论极限的方法。

Shannon's theorem is remarkable because it not only applies to all sequences in which elements are independent, but also to structured sequences like English text; that is, sequences which contain short-range and long-range dependencies between their elements. But before we can appreciate Shannon's source coding theorem, we need to know more about channel capacity, which was introduced in Chapter 2.

香农定理的卓越之处在于，它不仅适用于元素相互独立的序列，也适用于英语文本这样的结构化序列，即元素之间具有短程和长程依赖关系的序列。在理解香农信源编码定理之前，我们需要进一步了解第 2 章介绍的信道容量。

3.2 Capacity of a Discrete Noiseless Channel / 离散无噪信道的容量#

The capacity (C) of a discrete noiseless channel is the maximum number of bits it can communicate, usually expressed in units of bits per second or bits per symbol. Given that a binary digit can convey a maximum of one bit, a channel which communicates at the rate of (R) binary digits per second can communicate information at the rate of (C=R) bits/s, its channel capacity. Thus, channel capacity is numerically equal to the number of binary digits communicated per second. Of course, if each binary digit carries less than one bit then the channel communicates information at a lower rate (R<C) bits/s. In practice, to achieve a rate (R) close to the channel capacity (C), the transmitted codewords must be used wisely.

离散无噪信道的容量 (C)，是它能够传递的最大比特数，通常以比特/秒或比特/符号表示。一个二进制数字最多可以传递一比特信息，因此，以 (R) 个二进制数字/秒传输的信道，其信息传输上限为 (C=R) 比特/秒，这就是信道容量。信道容量在数值上等于每秒传递的二进制数字数。当然，如果每个二进制数字携带的信息少于一比特，实际信息速率就会降低为 (R<C) 比特/秒。实践中，要使速率 (R) 接近容量 (C)，必须合理使用所传输的码字。

Consider a source which generates a stream of data in the form of symbols (s_1,s_2,\ldots), with an entropy of (H(S)) bits per symbol, and a channel which transmits the corresponding encoded inputs (x_1,x_2,\ldots), where each input consists of (C) binary digits. Each symbol could, for example, consist of eight binary digits, where each binary digit carries only half a bit of information, as in the final part of Section 1.8; in the absence of any encoding, i.e. (x_i=s_i), each input would carry only (C/2) bits of information. To pre-empt the next section, Shannon's source coding theorem guarantees that for any message there exists an encoding of symbols such that each channel input of (C) binary digits can convey, on average, close to (C) bits of information.

考虑一个信源，它以符号 (s_1,s_2,\ldots) 的形式生成数据流，熵为每个符号 (H(S)) 比特；另有一个信道传输相应的编码输入 (x_1,x_2,\ldots)，每个输入由 (C) 个二进制数字构成。例如，每个符号可能包含八个二进制数字，而每个二进制数字只携带半比特信息，如第 1.8 节末尾所述；如果完全不编码，即 (x_i=s_i)，每个输入只携带 (C/2) 比特信息。先预告下一节的结论：香农信源编码定理保证，对任何消息都存在一种符号编码，使每个由 (C) 个二进制数字组成的信道输入平均能够携带接近 (C) 比特的信息。

This encoding process yields inputs with a specific distribution (p(X)). The shape of this distribution determines its entropy (H(X)), and therefore how much information each input carries. Thus, the capacity of a channel is defined in terms of the particular distribution (p(X)) which maximises the amount of information per input, i.e.

这种编码过程产生具有特定分布 (p(X)) 的输入。分布形状决定它的熵 (H(X))，从而决定每个输入携带的信息量。因此，信道容量用使每个输入的信息量达到最大的那个分布 (p(X)) 来定义：

$$ C=\max_{p(X)}H(X)\ \text{bits per input}. \tag{3.1} $$

This states that channel capacity (C) is achieved by the distribution (p(X)) which makes (H(X)) as large as possible. If the channel transmits one input per second, for example, then we can state this in terms of the number of bits per second,

这表示，使 (H(X)) 尽可能大的分布 (p(X)) 能够达到信道容量 (C)。例如，如果信道每秒传输一个输入，就可以用每秒比特数表示：

$$ C=\max_{p(X)}H(X)\ \text{bits/s}, \tag{3.2} $$

so that the maximum number of symbols communicated per second is

因而每秒能够传递的最大符号数为：

$$ \frac{C}{H(X)}\ \text{symbols/s}. \tag{3.3} $$

It can be shown that a uniform distribution (p(X)) maximises (H(X)).

可以证明，均匀分布 (p(X)) 使 (H(X)) 达到最大。

An equivalent definition of capacity was given by Shannon48. He defined the channel capacity of a noiseless channel as the logarithm of the number (N(t)) of inputs, or encoded messages, that can be communicated through the channel in a time interval (t), given by

香农48还给出了一个等价定义。他把无噪信道的容量定义为：在时间间隔 (t) 内能够通过信道传递的输入，也就是编码消息，数量 (N(t)) 的对数：

$$ C=\lim_{t\to\infty}\frac{\log N(t)}{t}\ \text{bits/s}. \tag{3.4} $$

Thus, as (t) approaches infinity, the logarithm of the number of encoded messages that can be conveyed per second approaches the channel capacity. The proviso 'as (t) approaches infinity' is included because some messages are encoded using extremely long codewords, which are averaged out when measuring over long time periods. If we omit this nicety then channel capacity is simply the logarithm of the number of distinguishable encoded messages that could be communicated each second.

因此，当 (t) 趋于无穷大时，每秒可传递编码消息数量的对数趋近于信道容量。加入“当 (t) 趋于无穷大”这一条件，是因为某些消息使用极长码字编码；在足够长的时间尺度上测量时，这些长度差异会被平均掉。如果略去这项技术细节，信道容量就是每秒可能传递的、彼此可区分的编码消息数量的对数。

This definition does not refer to the number of encoded messages actually communicated per second, but to the number of different encoded messages that could be communicated per second. For example, you may be able to say one word per second, but you choose each word from a vocabulary of about (m=1{,}000) words. If we assume you are a channel then you could generate information at a maximum rate of (\log1000=9.96) bits/s, which is, by definition, your channel capacity.

这个定义指的不是每秒实际传递了多少编码消息，而是每秒可能传递多少种不同的编码消息。例如，你也许每秒只能说一个词，但每个词都从大约 (m=1{,}000) 个词的词汇表中选择。如果把你看作一个信道，你生成信息的最大速率就是 (\log1000=9.96) 比特/秒；根据定义，这就是你的信道容量。

However, this capacity can only be achieved if (1) you generate all words equally often, and (2) you generate words in random order, i.e. the words are iid. If you do not generate all words equally often then some words will be more frequent, making them less surprising, so that they convey less Shannon information than others. Similarly, if you do not generate words in random order then some words will be fairly predictable; in a common phrase like thank you, the word you is very predictable. By definition, predictable words are unsurprising and convey less Shannon information. Thus, any inequality in word frequency, or any redundancy between words, means that information is generated below channel capacity.

不过，要达到这个容量，必须满足两个条件：（1）所有词出现得同样频繁；（2）各词按随机顺序生成，即独立同分布。如果词频不相等，一些词就会更常见、更不令人惊讶，因此携带的香农信息更少。如果词序不是随机的，一些词就容易预测；例如在常见短语 thank you 中，you 非常容易预测。根据定义，可预测的词不令人惊讶，携带的香农信息也较少。因此，词频的任何不均等或词语之间的任何冗余，都会使信息生成速率低于信道容量。

Consider a channel that can convey nine binary digits per second. Each set of nine binary digits can adopt one out of (N=2^9) binary numbers, so the message actually sent in one second is chosen from (N=2^9) possible messages. Similarly, in (t) seconds a total of (9t) binary digits can be sent, and the resulting message is one out of (2^{9t}) possible messages. According to Equation 3.4, the capacity is

考虑一个每秒能够传递九个二进制数字的信道。每组九个二进制数字可以取 (N=2^9) 个二进制数之一，因此一秒内实际发送的消息，是从 (N=2^9) 条可能消息中选出的。同样，在 (t) 秒内可以发送 (9t) 个二进制数字，所得消息是 (2^{9t}) 条可能消息之一。根据公式 (3.4)，信道容量为：

$$ C=\frac{\log 2^{9t}}{t}=\frac{9t}{t}=9\ \text{bits/s}. \tag{3.5} $$

In other words, if a channel conveys nine binary digits per second then the maximum amount of information it can convey, i.e. its capacity, is an average of nine bits per second. We have not done anything new in this section, except to define channel capacity and check that it makes intuitive sense.

换句话说，如果信道每秒传递九个二进制数字，它能够传递的最大信息量，也就是容量，平均为九比特/秒。本节并没有引入新的操作，只是定义了信道容量，并确认它符合直觉。

Key point. The capacity (C) of a noiseless channel is the maximum number of bits it can communicate per second, and is numerically equal to the number of binary digits it communicates per second.

要点：无噪信道的容量 (C) 是它每秒能够传递的最大比特数，在数值上等于它每秒传递的二进制数字数。

3.3 Shannon's Source Coding Theorem / 香农信源编码定理#

Now that we are familiar with the core concepts of information theory, we can quote Shannon's source coding theorem in full. This is also known as Shannon's fundamental theorem for a discrete noiseless channel, and as the first fundamental coding theorem.

现在我们已经熟悉信息论的核心概念，可以完整引用香农信源编码定理。它也称为“离散无噪信道的香农基本定理”或“第一编码基本定理”。

Let a source have entropy (H) (bits per symbol) and a channel have a capacity (C) (bits per second). Then it is possible to encode the output of the source in such a way as to transmit at the average rate (C/H-\epsilon) symbols per second over the channel where (\epsilon) is arbitrarily small. It is not possible to transmit at an average rate greater than (C/H) [symbols/s].

设一个信源的熵为 (H)（比特/符号），一个信道的容量为 (C)（比特/秒）。那么，可以对信源输出进行编码，使其通过信道以平均 (C/H-\epsilon) 个符号/秒的速率传输，其中 (\epsilon) 可以任意小。不可能以高于 (C/H) [符号/秒] 的平均速率进行传输。

Shannon and Weaver, 194950.

[Text in square brackets has been added by the author. / 方括号中的文字由本书作者补充。]

The Greek letter (\epsilon), epsilon, is traditionally used to denote a very small quantity. In essence, Shannon's source coding theorem states that messages from a source which generates information at the rate of (H) bits/s can be encoded so that they can be transmitted at a rate arbitrarily close to the capacity (C) of a channel, provided (H<C). To modern eyes, familiar with computers, this may seem circular. However, in Shannon's day it was a revelation.

希腊字母 (\epsilon) 通常表示一个很小的量。香农信源编码定理的核心含义是：只要 (H<C)，以 (H) 比特/秒生成信息的信源消息就可以被编码，使其以任意接近信道容量 (C) 的速率传输。对熟悉计算机的现代人来说，这也许像是循环论证；但在香农所处的时代，这是一项具有启示性的发现。

3.4 Calculating Information Rates / 信息速率的计算#

Channel capacity (C) is usually expressed in bits/s; for a binary channel this means that it communicates (C) binary digits/s. Full capacity is used only if source outcomes are encoded so that each transmitted binary digit represents an average of one bit. We consider two die examples, which avoid complications caused by variables that are not iid.

信道容量 (C) 通常以比特/秒表示；对于二进制信道，这意味着每秒传输 (C) 个二进制数字。只有当信源结果被编码为每个二进制数字平均表示一比特信息时，信道容量才得到充分利用。下面用两个骰子例子强化这种直觉，并避开非独立同分布变量带来的问题。

Coding for an 8-Sided Die / 八面骰子的编码#

Suppose a telephone signal is quantised each millisecond as a value from 1 to 8. Ignoring dependencies between consecutive values, this resembles outcomes from an 8-sided die. Each of the eight equally probable, independent symbols (A_S={s_1,\ldots,s_8}) can be encoded with exactly three binary digits because (3=\log8). Each outcome therefore conveys (H=3) bits/symbol.

假设电话信号每毫秒被量化为 1 到 8 之间的一个值。忽略连续值之间的依赖关系，这类似于八面骰子的结果。八个等概率、相互独立的符号 (A_S={s_1,\ldots,s_8}) 均可用三个二进制数字精确编码，因为 (3=\log8)。因此，每个结果携带 (H=3) 比特/符号。

Symbol / 符号 Codeword / 码字 Symbol / 符号 Codeword / 码字
(s_1=1) (x_1=000) (s_5=5) (x_5=100)
(s_2=2) (x_2=001) (s_6=6) (x_6=101)
(s_3=3) (x_3=010) (s_7=7) (x_7=110)
(s_4=4) (x_4=011) (s_8=8) (x_8=111)

Table 3.1. Each outcome (s) from an 8-sided die has a value which can be represented as a 3-digit binary codeword (x).

表 3.1　八面骰子的每个结果 (s) 都可以表示为一个三位二进制码字 (x)。

If (C=3) bits/s, simple decimal-to-binary conversion, minus one, gives the required code. For example, (s_4=4) is encoded as (x_4=011) and decoded as 4. The maximum symbol rate is

如果 (C=3) 比特/秒，简单地把十进制数减一后转换为二进制即可得到所需编码。例如，(s_4=4) 编码为 (x_4=011)，接收后再解码为 4。最大符号速率为：

$$R=C/H \tag{3.6}$$ $$=\frac{3\ \text{bits/s}}{3\ \text{bits/symbol}} \tag{3.7}$$ $$=1\ \text{symbol/s}. \tag{3.8}$$

This is an efficient code because information is communicated at the channel capacity. If average codeword length is (L(X)), coding efficiency is

该编码以信道容量传递信息，因此是高效编码。若平均码字长度为 (L(X))，编码效率为：

$$\frac{H(S)}{L(X)}=\frac{3\ \text{bits/symbol}}{3\ \text{binary digits/symbol}} \tag{3.9}$$ $$=1\ \text{bit/binary digit}. \tag{3.10}$$

Coding efficiency ranges from zero to one, so this code is maximally efficient.

编码效率介于 0 和 1 之间，因此该编码达到最大效率。

Coding for a 6-Sided Die / 六面骰子的编码#

For a 6-sided die, outcomes define

六面骰子的结果定义字母表：

$$A_S={1,2,3,4,5,6} \tag{3.11}$$ $$={s_1,s_2,s_3,s_4,s_5,s_6}. \tag{3.12}$$

Each symbol provides an average of

每个符号平均提供：

$$H=\log6 \tag{3.13}$$ $$=2.58\ \text{bits/symbol}. \tag{3.14}$$

In principle, each symbol can therefore be encoded with an average of 2.58 binary digits. For a channel with (C=1) bit/s, the theorem gives

因此原则上，每个符号平均可用 2.58 个二进制数字编码。对于 (C=1) 比特/秒的信道，定理给出：

$$R=C/H \tag{3.15}$$ $$=\frac{1\ \text{bit/s}}{2.58\ \text{bits/symbol}} \tag{3.16}$$ $$=0.387\ \text{symbols/s}. \tag{3.17}$$

A first attempt uses three binary digits per symbol, taking the first six rows of Table 3.1. Its efficiency is only

第一种尝试是采用表 3.1 的前六行，每个符号使用三个二进制数字。其效率仅为：

$$\frac{H(S)}{L(X)}=\frac{2.58}{3} \tag{3.18}$$ $$=0.86\ \text{bits/binary digit}. \tag{3.19}$$

The corresponding rate is

相应的传输速率为：

$$R=C/H \tag{3.20}$$ $$=\frac{0.86\ \text{bits/s}}{2.58\ \text{bits/symbol}} \tag{3.21}$$ $$=0.333\ \text{symbols/s}, \tag{3.22}$$

below the theoretical 0.387 symbols/s. A better code combines three die outcomes. There are (6^3=216) possible triplets, which can be labelled using eight binary digits because (2^8=256). Thus each symbol uses (8/3\approx2.66) binary digits, and efficiency becomes

这低于理论上限 0.387 符号/秒。更好的方法把三次骰子结果合并编码。共有 (6^3=216) 种三元组，而八个二进制数字可以提供 (2^8=256) 个标签。因此，每个符号使用 (8/3\approx2.66) 个二进制数字，效率提高为：

$$\frac{H(S)}{L(X)}=\frac{2.58}{2.66} \tag{3.23}$$ $$=0.970\ \text{bits/binary digit}. \tag{3.24}$$

The rate is consequently

因而传输速率为：

$$\frac{0.970\ \text{bits/s}}{2.58\ \text{bits/symbol}} \tag{3.25}$$ $$=0.376\ \text{symbols/s}, \tag{3.26}$$

which is much closer to the maximum.

这已经非常接近最大速率。

Key point. If each independently chosen value represents a non-integer number of bits, efficient encoding can be obtained by combining several symbols in one binary codeword.

要点：如果每个独立取值表示非整数比特数，可以把多个符号合并进一个二进制码字，从而获得高效编码。

3.5 Data Compression / 数据压缩#

The preceding examples used uniform distributions. The importance of the ideas becomes clearer for non-uniform distributions. Throwing two 6-sided dice gives an ordered pair; if the outcome value is their sum, the alphabet contains (m=11) values:

这枚想象中的 9.65 面骰子说明，熵如何把非均匀分布转换为等价的等概率结果数。

3.6 Huffman Coding / 霍夫曼编码#

Huffman coding, invented by David Huffman in 1952, efficiently maps message symbols to codewords. Frequent symbols receive short codewords and rare symbols long ones, so the average transmitted length is small. For independent symbols, its lossless compression approaches message entropy; with binary coding, 0s and 1s occur at roughly equal frequencies.

霍夫曼编码由 David Huffman 于 1952 年发明，用于把消息符号高效映射为码字。常见符号得到短码字，罕见符号得到长码字，从而缩短平均传输长度。对于相互独立的符号，它实现的无损压缩接近消息熵；采用二进制编码时，0 和 1 出现的频率大致相等。

The source coding theorem for symbol codes34 states that for a discrete variable (X) with entropy (H(X)), there exists a symbol code whose expected codeword length (L(X)) satisfies

符号码的信源编码定理34指出，对于熵为 (H(X)) 的离散变量 (X)，存在一种符号编码，其期望码字长度 (L(X)) 满足：

$$H(X)\le L(X)<H(X)+1. \tag{3.37}$$

Huffman coding repeatedly combines the two least probable symbols into an imaginary composite symbol whose probability is their sum. Upper and lower branches are labelled 1 and 0, and the process continues until one symbol remains. Reading branch labels from the root to each original symbol yields its codeword.

霍夫曼编码反复把概率最低的两个符号合并成一个虚拟复合符号，其概率等于二者概率之和。上下分支分别标记为 1 和 0，直到只剩一个符号。沿树根到各原始符号读取分支标签，即得到对应码字。

Figure 3.3. Simple Huffman code for five symbols A-E. Reading from right to left in the original tree gives (A=1), (B=011), (C=010), (D=001), and (E=000).

图 3.3　五个符号 A-E 的简单霍夫曼码。按原图从右向左读取，得到 (A=1)、(B=011)、(C=010)、(D=001)、(E=000)。

For the dice code in Table 3.2, if codeword (x_i) has length (L(x_i)), average length is

对表 3.2 的骰子编码，若码字 (x_i) 的长度为 (L(x_i))，平均长度为：

$$L(X)=\sum_{i=1}^{m=11}p(s_i)L(x_i) \tag{3.38}$$ $$=3.31\ \text{binary digits/symbol}. \tag{3.39}$$

Efficiency is

编码效率为：

$$\frac{H(S)}{L(X)}=\frac{3.27}{3.31} \tag{3.40}$$ $$=0.99\ \text{bits/binary digit}. \tag{3.41}$$

The average length is less than one digit above entropy, satisfying Equation 3.37. Huffman codes are also prefix codes: no codeword is the prefix of another, so boundaries between consecutive codewords are unambiguous.

平均长度比熵多不到一个二进制数字，满足公式 (3.37)。霍夫曼码还是前缀码：任何码字都不是另一码字的前缀，因此连续码字之间的边界不会产生歧义。

Huffman Coding of Images / 图像的霍夫曼编码#

图 1.8 中的 127 个灰度差若采用简单固定编码，每个约需七位。霍夫曼编码得到的平均长度为 (L=5.97)，仅略高于实测熵 (H=5.94)，因此：

$$\frac{H(S)}{L(X)}=\frac{5.94}{5.97}=0.99\ \text{bits/binary digit}. \tag{3.42}$$

This remains an over-estimate because it ignores dependencies between nearby pixels. Huffman coding efficiently encodes symbol frequencies but does not remove dependencies between nearby symbols, which matters for images and English.

这仍是高估，因为它忽略了相邻像素的依赖关系。霍夫曼编码能高效利用符号频率，却不消除相邻符号之间的依赖；对图像和英语而言，这一点十分重要。

3.7 The Entropy of English Letters / 英语字母的熵#

How can we estimate the entropy of a Shakespeare play, or any letter sequence whose consecutive letters are not independent? The short answer is to express letter probabilities using mutually independent blocks, then use the standard entropy definition. The account below summarises Shannon's proof.

怎样估计一部莎士比亚戏剧，或任意相邻字母不独立的序列的熵？简短答案是：用相互独立的字母块表示字母概率，再应用标准熵定义。下面概述香农的证明思路。

English Entropy: Informal Account / 英语熵：非正式说明#

The probability of a letter depends on letters before and after it, so it is a conditional probability. Accurate conditional probabilities require context and are difficult to estimate. The relative frequencies in Table 3.3 and Figure 3.4 are unconditional probabilities. Entropy based only on these frequencies is too large, because conditional information makes letters more predictable.

一个字母的概率取决于它前后的字母，因此属于条件概率。准确估计条件概率需要考虑上下文，而且非常困难。表 3.3 和图 3.4 中的相对频率则是无条件概率。仅根据这些频率估计的熵会偏大，因为上下文条件会使字母更容易预测。

Figure 3.4. Relative frequency of letters in Shakespeare's Romeo and Juliet. This distribution has entropy (G_1=4.12) bits/letter.

图 3.4　莎士比亚《罗密欧与朱丽叶》中的字母相对频率。该分布的熵为 (G_1=4.12) 比特/字母。

The Shannon information of a letter is related to its predictability from context. Predictability increases, and uncertainty decreases, as more surrounding letters are considered. Averaged over all letters, uncertainty eventually stops decreasing at an 'uncertainty horizon'; there the average uncertainty equals the entropy of English.

字母的香农信息与根据上下文预测它的难易程度有关。考虑的周围字母越多，可预测性越高，不确定性越低。对所有字母取平均后，不确定性最终会在某个“不确定性视界”停止下降；此时的平均不确定性就是英语的熵。

Figure 3.5. Letter predictability should increase with increasing context. By Randall Munroe, reproduced with permission from xkcd.com.

图 3.5　随着上下文增加，字母的可预测性应当提高。作者 Randall Munroe，经 xkcd.com 授权转载。

Figure 3.6. Entropy per letter (G_N) decreases as the number (N) of letters considered increases, using a corpus of 70 million characters45. As (N) grows, (G_N) approaches English entropy (H).

图 3.6　基于 7,000 万字符语料库45，每字母熵 (G_N) 随所考虑字母数 (N) 增加而降低。随着 (N) 增大，(G_N) 趋近英语熵 (H)。

Strictly, entropy applies to an ensemble of English sequences rather than one particular sequence, whose estimated entropy may depend on its starting letter. The ensemble is conceptually infinite, though practical estimates always use finite observations.

严格来说，熵适用于英语字母序列的系综，而不是某个特定序列；后者的估计熵可能受首字母影响。系综在概念上包含无限多个序列，但实际估计总是基于有限观测。

English Entropy: A More Formal Account / 英语熵：更形式化的说明#

Consider consecutive, non-overlapping blocks of (N) letters. For (N=1), each letter probability is estimated by relative frequency and gives first-order approximation (G_1). For (N=2), the two letters in each block constrain one another, so average uncertainty (G_2<G_1). Similarly (G_3<G_2). Longer blocks become increasingly independent of other blocks.

考虑由 (N) 个连续且不重叠的字母组成的块。当 (N=1) 时，用相对频率估计字母概率，得到一阶近似 (G_1)。当 (N=2) 时，块内两个字母相互约束，所以平均不确定性 (G_2<G_1)。同理，(G_3<G_2)。随着块变长，不同块之间越来越接近独立。

Figure 3.7. As block size increases from (N=1) to (N=3), prediction from other letters in the same block improves, so mean surprisal per letter decreases.

图 3.7　当块大小从 (N=1) 增加到 (N=3) 时，利用同一块内其他字母进行预测的能力增强，因此每个字母的平均惊异量下降。

Figure 3.8. Relative frequencies of ordered letter pairs in Romeo and Juliet. Each column represents one ordered pair.

图 3.8　《罗密欧与朱丽叶》中有序字母对的相对频率。每一列表示一个有序字母对。

Suppose a letter depends on no letter more than 10 positions away. Once (N=10), a block depends only on itself and its immediate neighbours. With many long blocks, this boundary dependence is negligible. The block length beyond which inter-letter dependence falls to zero is the correlation length (N_c). For (N>N_c), blocks are effectively independent and (G_N) no longer decreases; hence (G_{N_c}=H). Shannon's infinite-block theorems therefore apply in practice once block length exceeds correlation length.

假设一个字母不依赖相距超过 10 位的字母。当 (N=10) 时，一个块只依赖自身及左右相邻块。在块数量多且长度足够大时，这种边界依赖可以忽略。字母间依赖降为零时的块长度称为相关长度 (N_c)。对 (N>N_c)，各块实际上相互独立，(G_N) 不再下降，因此 (G_{N_c}=H)。所以，香农以无限块长表述的定理，在实际中只要块长超过相关长度就适用。

Key point. As the number of letters in each block increases, the average uncertainty of each letter decreases.

要点：每个块包含的字母越多，每个字母的平均不确定性越低。

English Entropy: Formal Account / 英语熵：形式化计算#

Using single-letter relative frequencies, including space as the 27th letter, gives

使用单字母相对频率，并把空格作为第 27 个字母，得到：

$$G_1=\sum_{i=1}^{m=27}p(x_i)\log\frac{1}{p(x_i)} \tag{3.43}$$ $$=4.08\ \text{bits/letter}. \tag{3.44}$$

These estimates use 70 million characters45; their frequencies differ slightly from Table 3.3. For (N=2), there are (27^2=729) ordered blocks (B_k=[x_i,y_j]). Dividing block entropy by two gives information per letter:

这些估计基于 7,000 万字符45，频率与表 3.3 略有不同。当 (N=2) 时，共有 (27^2=729) 个有序块 (B_k=[x_i,y_j])。把块熵除以 2 得到每字母信息量：

$$G_2=\frac{1}{2}\sum_{k=1}^{729}p(B_k)\log\frac{1}{p(B_k)} \tag{3.45}$$ $$=\frac{1}{2}H(B) \tag{3.46}$$ $$=3.32\ \text{bits/letter}. \tag{3.47}$$

This remains an over-estimate because dependencies can extend beyond two letters. For (N=3), there are (27^3=19{,}683) triplets:

这仍然是高估，因为依赖关系可能跨越两个以上的字母。当 (N=3) 时，共有 (27^3=19{,}683) 个三元组：

$$G_3=\frac{1}{3}\sum_{k=1}^{19{,}683}p(B_k)\log\frac{1}{p(B_k)} \tag{3.48}$$ $$=\frac{1}{3}H(B) \tag{3.49}$$ $$=2.73\ \text{bits/letter}. \tag{3.50}$$

Common triplets such as and and the dominate the weighted average, while rare triplets contribute little. The key insight is that a small fraction of possible subsequences are common and most are nearly absent.

and、the 等常见三元组主导加权平均，而罕见三元组贡献很小。关键洞见是：所有可能子序列中只有很小一部分常见，绝大多数几乎从不出现。

For arbitrary block length (N),

对任意块长 (N)：

$$G_N=\frac{1}{N}\sum_{k=1}^{27^N}p(B_k)\log\frac{1}{p(B_k)}\ \text{bits/letter}. \tag{3.51}$$

Once dependencies up to (N_c) have been included, (G_{N_c}=H). In practice estimates converge to about 1.8 bits/letter. The source coding theorem then guarantees communication using only slightly more than 1.8 binary digits per letter.

一旦计入直到 (N_c) 的全部依赖关系，就有 (G_{N_c}=H)。实际估计收敛到约 1.8 比特/字母。信源编码定理于是保证，英语可以用每字母略多于 1.8 个二进制数字传输。

Efficient Transmission of English / 英语的高效传输#

Assume (N_c=10). The number of possible 10-letter subsequences is

假设 (N_c=10)。可能的十字母子序列数量为：

$$m_c=27^{10} \tag{3.52}$$ $$\approx206\times10^{12}, \tag{3.53}$$

which, if equiprobable, would require

如果它们等概率出现，需要：

$$\log(206\times10^{12})=47.5\ \text{binary digits}. \tag{3.54}$$

Shannon proved that the common subsequences form a tiny fraction of all possibilities, have collective probability near one, and are approximately equiprobable. With (H=1.8) bits/letter, the number of observed equiprobable 10-letter blocks is

香农证明，常见子序列只占全部可能性的一小部分，合计概率接近 1，而且彼此近似等概率。当 (H=1.8) 比特/字母时，实际观察到的等概率十字母块数量为：

$$m_H=2^{1.8\times10} \tag{3.55}$$ $$=262{,}144, \tag{3.56}$$

so each block needs only

因此每个块只需要：

$$\log_2 2^{1.8\times10}=18\ \text{binary digits}. \tag{3.57}$$

The remaining more than 205 trillion possible blocks have collective probability near zero. Since the common 262,144 blocks are approximately equiprobable, Huffman coding offers no further saving.

其余超过 205 万亿个可能块的合计概率接近零。由于常见的 262,144 个块近似等概率，霍夫曼编码无法进一步节省长度。

A practical codebook can rank 10-letter blocks by frequency, assign 18-bit codewords to the 262,144 most common blocks, and give the same table to sender and receiver. A message is divided into 10-letter blocks, replaced by codewords, transmitted, and looked up at the receiver. What appears to need 47.5 digits per block, or 4.75 per letter, is sent using 18 per block, or 1.8 per letter.

实际上，可以按频率排列十字母块，为最常见的 262,144 个块分配 18 位码字，并让发送端与接收端共享同一码本。消息被分成十字母块，替换为码字后传输，接收端再查表恢复。原本看似每块需要 47.5 位、每字母需要 4.75 位的消息，最终只需每块 18 位、每字母 1.8 位。

Before Shannon, Morse devised a conceptually similar list of common phrases, assigning each a number. Sending the phrase number rather than the whole phrase exploited the fact that possible messages vastly outnumber messages actually used.

早在香农之前，Morse 就设计过概念相近的常用短语表，为每个短语分配编号。发送短语编号而不是完整短语，利用了“可能消息数量远大于实际使用消息数量”这一事实。

What's in a name? That which we call a rose
By any other name would smell as sweet.

名字究竟有什么意义？我们称作玫瑰的花，
换一个名字，也依然芬芳。

Shakespeare W, 1597.

For communication, it is not the name itself that matters, but the number of possible words from which the name was chosen. The same block argument applies to images, music, movies, DNA and other natural sequences.

对通信而言，重要的不是名称本身，而是这个名称从多少个可能词中被选出。同样的分块论证也适用于图像、音乐、电影、DNA 以及其他自然序列。

3.8 Why the Theorem is True / 定理为什么成立#

The source coding theorem rests on the observation that most events which could occur almost certainly do not, while those that do occur have roughly equal probabilities. A counting argument gives an outline of Shannon's proof.

信源编码定理建立在一个观察之上：绝大多数理论上可能发生的事件几乎肯定不会发生，而实际发生的事件彼此具有近似相同的概率。下面用计数论证概述香农证明的核心。

Consider a source generating messages of (n) iid binary digits (\mathbf{s}=(s_1,\ldots,s_n)), where the stable probability of a 1 is (P). In principle it can generate (m_{\max}=2^n) messages, but in practice almost all generated messages contain about (nP) ones, by the law of large numbers, and the number (m) of distinct common messages is much smaller.

考虑一个信源，它生成由 (n) 个独立同分布二进制数字构成的消息 (\mathbf{s}=(s_1,\ldots,s_n))，其中数字 1 的稳定概率为 (P)。原则上它可以生成 (m_{\max}=2^n) 条消息；但根据大数定律，实际生成的几乎所有消息都包含约 (nP) 个 1，因此常见的不同消息数量 (m) 要小得多。

For illustration take (n=8):

以 (n=8) 为例：

$$\mathbf{s}=(s_1,s_2,s_3,s_4,s_5,s_6,s_7,s_8). \tag{3.58}$$

If (P=1/8=0.125), then (nP=1), so the most common messages contain one 1 and seven 0s. There are exactly eight such messages. Their common probability is

如果 (P=1/8=0.125)，则 (nP=1)，最常见的消息包含一个 1 和七个 0，共有八条。每条这种消息的概率为：

$$P_1P_2\cdots P_8=0.125\times0.875^7 \tag{3.59}$$ $$=0.049. \tag{3.60}$$

The position of the 1 does not affect probability, so all eight messages are equiprobable. Although this exact claim is an approximation for short messages, it becomes overwhelmingly accurate for large (n).

1 所在的位置不影响概率，因此八条消息等概率。对短消息而言，这只是近似；当 (n) 很大时，它会变得极其准确。

Eight equiprobable messages require

八条等概率消息需要：

binary digits per codeword,

个二进制数字，因此码字为：

$$\mathbf{x}=(x_1,\ldots,x_3). \tag{3.63}$$

Assuming these eight comprise essentially all generated messages, each has relative frequency

假设实际生成的消息基本都属于这八条，则每条消息的相对频率为：

$$p=1/m \tag{3.64}$$ $$=0.125. \tag{3.65}$$

This is distinct from Equation 3.60, the probability that a short message has one 1. Entropy is

这不同于公式 (3.60) 中“短消息包含一个 1”的概率。熵为：

$$H=E[\log(1/p)] \tag{3.66}$$ $$=\log m \tag{3.67}$$ $$=3\ \text{bits/message}. \tag{3.68}$$

Thus eight-digit source messages have only three bits of effective entropy and can be recoded with three digits. If (P=0.5), all (2^n) messages are typical and (H=n); otherwise the typical set is smaller.

因此，八位信源消息的有效熵只有三比特，可以重新编码为三位。若 (P=0.5)，全部 (2^n) 条消息都是典型消息且 (H=n)；否则典型集合更小。

Why Does the Source Generate Only (m) Distinct Messages? / 为什么信源只生成 (m) 种不同消息？#

The number of length-(n) messages containing (n_1) ones and (n_0) zeros is the binomial coefficient

长度为 (n)、包含 (n_1) 个 1 和 (n_0) 个 0 的消息数量，是二项式系数：

$$C_{n,n_1}=\frac{n!}{n_1!n_0!}, \tag{3.69}$$

where (n!=n(n-1)\cdots1). Summing over all possible (n_1) gives

其中 (n!=n(n-1)\cdots1)。对全部可能的 (n_1) 求和得到：

$$\sum_{n_1=0}^{n}C_{n,n_1}=2^n. \tag{3.70}$$

For long messages almost all generated messages have (nP) ones, so

对长消息而言，几乎全部实际消息都含 (nP) 个 1，因此：

$$\sum_{n_1=0}^{n}C_{n,n_1}\approx C_{n,nP} \tag{3.71}$$ $$=m, \tag{3.72}$$

with (m<2^n). Using natural logarithms and Stirling's approximation (\ln n!\approx n(\ln n-1)),

且 (m<2^n)。使用自然对数和斯特林近似 (\ln n!\approx n(\ln n-1))：

$$\ln C_{n,n_1}=\ln n!-\ln n_1!-\ln n_0! \tag{3.73}$$ $$\ln m\approx n(\ln n-1)-n_1(\ln n_1-1)-n_0(\ln n_0-1) \tag{3.74}$$ $$=n\ln n-n_1\ln n_1-n_0\ln n_0-[n-(n_1+n_0)] \tag{3.75}$$ $$=(n_0+n_1)\ln n-n_1\ln n_1-n_0\ln n_0 \tag{3.76}$$ $$=n_1(\ln n-\ln n_1)+n_0(\ln n-\ln n_0) \tag{3.77}$$ $$=n_1\ln\frac{n}{n_1}+n_0\ln\frac{n}{n_0} \tag{3.78}$$ $$=n\left(p_1\ln\frac{1}{p_1}+p_0\ln\frac{1}{p_0}\right). \tag{3.79}$$

Substituting (p_1=n_1/n) and (p_0=n_0/n), then changing to base 2, yields

代入 (p_1=n_1/n)、(p_0=n_0/n)，再改用以 2 为底的对数，得到：

$$\log_2m=n\left(p_1\log_2\frac{1}{p_1}+p_0\log_2\frac{1}{p_0}\right) =n\sum_{i=0}^{1}p_i\log_2\frac{1}{p_i}\ \text{bits/message}. \tag{3.80}$$

This is exactly the entropy of an (n)-digit binary message. The argument is not a fully rigorous proof, but captures the mechanism behind Shannon's result.

这正是包含 (n) 个二进制数字的消息的熵。上述论证并非严格的完整证明，但抓住了香农结果背后的机制。

3.9 Kolmogorov Complexity / 柯尔莫哥洛夫复杂度#

Andrey Kolmogorov independently developed the compression interpretation. Algorithmic, or Kolmogorov, complexity is the length of the shortest computer program capable of describing an object.

Andrey Kolmogorov 独立发展了这种压缩解释。算法复杂度，也就是柯尔莫哥洛夫复杂度，是能够描述某个对象的最短计算机程序长度。

For example, the first million digits of (\pi) can be generated by a program much shorter than one million digits. One formula is Leibniz's series,

例如，(\pi) 的前一百万位可以由远短于一百万位的程序生成。Leibniz 级数为：

$$\pi=4\left(1-\frac{1}{3}+\frac{1}{5}-\frac{1}{7}+\frac{1}{9}-\cdots\right), \tag{3.81}$$

or

或写为：

$$\pi=4\sum_{k=0}^{\infty}\frac{(-1)^k}{2k+1}. \tag{3.82}$$

A simple loop can generate infinitely many digits. If the shortest such program has (n_\pi) binary digits, those digits must carry (n_\pi) bits; otherwise a shorter representation would exist. Thus an apparently random infinite sequence is represented by a finite program, and its Kolmogorov complexity is (n_\pi) bits. For a random sequence, Kolmogorov complexity is approximately its entropy.

一个简单循环就可以不断生成数字。若最短程序包含 (n_\pi) 个二进制数字，这些数字必然携带 (n_\pi) 比特；否则还会存在更短表示。因此，看似随机的无限序列可以由有限程序表示，其柯尔莫哥洛夫复杂度为 (n_\pi) 比特。对随机序列而言，柯尔莫哥洛夫复杂度近似等于其熵。

Kolmogorov complexity is non-computable: no definite algorithm can prove that a given program is the shortest, except exhaustive search over all programs. However brief a program for (\pi) may be, we can never be certain that a shorter one does not exist.

柯尔莫哥洛夫复杂度是不可计算的：除了穷举全部程序之外，没有确定算法能够证明某个程序已经最短。无论生成 (\pi) 的程序多么简短，我们都无法确定不存在更短程序。

3.10 Summary / 小结#

Shannon's source coding theorem concerns efficient encoding of messages into codewords, which is a form of data compression. We first examined channel capacity, the maximum rate at which information can pass through a channel. Some codes are inefficient because each binary digit carries much less than the upper limit of one bit. We then considered sources whose symbols are dependent and found that they can be encoded as independent blocks. Consequently, the theorem applies not only to iid sources but also to natural sequences such as English and images.

香农信源编码定理讨论如何把消息高效编码为码字，本质上是一种数据压缩。我们首先考察信道容量，即信息通过信道的最大速率。有些编码效率很低，因为每个二进制数字携带的信息远少于一比特上限。随后，我们考察符号相互依赖的信源，发现可以把它们编码为彼此独立的块。因此，该定理不仅适用于独立同分布信源，也适用于英语、图像等自然序列。
