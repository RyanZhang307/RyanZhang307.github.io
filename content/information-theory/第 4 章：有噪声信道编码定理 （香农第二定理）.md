# Chapter 4: The Noisy Channel Coding Theorem

## 4.1 Introduction / 引言

A noisy channel can change a transmitted input \(X\) into a different output \(Y\). The central questions are how much information survives, how channel noise should be measured, and whether reliable communication remains possible.

> 有噪信道可能把发送的输入 \(X\) 改变为不同的输出 \(Y\)。本章的核心问题是：有多少信息得以保留、怎样测量信道噪声，以及在噪声存在时能否实现可靠通信。

> **图 4.1　有噪通信信道在输入与输出之间加入噪声 \(\eta\)。**

## 4.2 Joint Distributions / 联合分布

Let source symbols be encoded as inputs \(X\), and let \(Y\) denote received outputs. Their alphabets and marginal distributions are

> 设信源符号被编码为输入 \(X\)，接收输出记为 \(Y\)。它们的字母表和边缘分布为：

$$A_X=\{x_1,\ldots,x_{m_X}\},\qquad p(X)=\{p(x_1),\ldots,p(x_{m_X})\},$$
$$A_Y=\{y_1,\ldots,y_{m_Y}\},\qquad p(Y)=\{p(y_1),\ldots,p(y_{m_Y})\}.$$

The joint probability \(p(x_i,y_j)\) is the probability that input \(x_i\) and output \(y_j\) occur as a corresponding pair. The complete joint distribution satisfies

> 联合概率 \(p(x_i,y_j)\) 表示输入 \(x_i\) 与输出 \(y_j\) 作为对应的一对同时出现的概率。完整联合分布满足：

$$\sum_i\sum_j p(x_i,y_j)=1,$$
$$p(x_i)=\sum_jp(x_i,y_j),\qquad p(y_j)=\sum_ip(x_i,y_j).$$

If \(X\) and \(Y\) are independent,

> 如果 \(X\) 与 \(Y\) 相互独立，则：

$$p(x_i,y_j)=p(x_i)p(y_j),\qquad p(X,Y)=p(X)p(Y),$$
$$H(X,Y)=H(X)+H(Y).$$

> **表 4.1-4.2　输入-输出对的计数及相应联合概率分布。图 4.2-4.3 展示同一分布及其边缘和。**

## 4.3 Mutual Information / 互信息

Mutual information measures the average information one variable provides about another:

> 互信息衡量一个变量平均能够提供多少关于另一个变量的信息：

$$I(X;Y)=\sum_i\sum_jp(x_i,y_j)\log\frac{p(x_i,y_j)}{p(x_i)p(y_j)}.$$

Equivalently,

> 等价地：

$$I(X;Y)=H(X)+H(Y)-H(X,Y).$$

For the numerical channel example in the chapter,

> 对本章的数值信道例子：

$$H(X)=1.81\ \text{bits},\quad H(Y)=1.99\ \text{bits},\quad H(X,Y)=3.30\ \text{bits},$$
$$I(X;Y)=1.81+1.99-3.30=0.509\ \text{bits}.$$

If variables are independent, mutual information is zero. If the output determines the input perfectly, mutual information equals input entropy.

> 若变量相互独立，互信息为零；若输出能够完全确定输入，互信息等于输入熵。

## 4.4 Conditional Entropy / 条件熵

Conditional entropy \(H(X\mid Y)\) is the uncertainty remaining about \(X\) after \(Y\) is known. Therefore,

> 条件熵 \(H(X\mid Y)\) 是已知 \(Y\) 后关于 \(X\) 仍然存在的不确定性。因此：

$$I(X;Y)=H(X)-H(X\mid Y)=H(Y)-H(Y\mid X),$$
$$H(X,Y)=H(Y)+H(X\mid Y)=H(X)+H(Y\mid X).$$

> **图 4.4　维恩图把重叠区域表示为 \(I(X;Y)\)，非重叠区域表示条件熵。**

## 4.5 Noise and Cross-Talk / 噪声与串扰

For an additive channel \(Y=X+\eta\), with noise independent of the input,

> 对加性信道 \(Y=X+\eta\)，若噪声与输入独立，则：

$$H(Y\mid X)=H(\eta),$$
$$I(X;Y)=H(Y)-H(\eta).$$

In the chapter's example,

> 在本章例子中：

$$H(\eta)=H(Y)-I(X;Y)=1.99-0.509=1.481\ \text{bits}.$$

Noise increases uncertainty about which input produced an output. Cross-talk similarly allows one channel or symbol stream to interfere with another.

> 噪声增加“哪个输入产生了当前输出”的不确定性。串扰则使一个信道或符号流干扰另一个信道或符号流。

**Figures 4.5-4.7. Entropy and fan diagrams show how noise spreads each input over several possible outputs and reduces their shared information.**

> **图 4.5-4.7　熵图和扇形图展示噪声如何把每个输入扩散为多个可能输出，并减少输入输出共享的信息。**

## 4.6 Noisy Pictures and Coding Efficiency / 含噪图像与编码效率

For the binary input image, black and white probabilities are 0.724 and 0.276:

> 对二值输入图像，黑白像素概率分别为 0.724 和 0.276：

$$H(X)=0.724\log\frac1{0.724}+0.276\log\frac1{0.276}=0.851\ \text{bits/pixel}.$$

For the noisy output image,

> 对含噪输出图像：

$$H(Y)=0.679\log\frac1{0.679}+0.322\log\frac1{0.322}=0.906\ \text{bits/pixel}.$$

The joint probabilities are approximately \(0.651,0.073,0.028,0.249\), giving

> 联合概率约为 \(0.651,0.073,0.028,0.249\)，因此：

$$H(X,Y)=1.321\ \text{bits},$$
$$I(X;Y)=0.851+0.906-1.321=0.436\ \text{bits/pixel}.$$

Thus less than half a bit per pixel is reliably shared between the clean and noisy images.

> 因此，干净图像与含噪图像之间每像素可靠共享的信息不足半比特。

## 4.7 Error Correcting Codes / 纠错码

If each binary digit is flipped independently with probability \(p=0.1\), channel noise entropy is

> 如果每个二进制数字以 \(p=0.1\) 的概率独立翻转，信道噪声熵为：

$$H(\eta)=p\log\frac1p+(1-p)\log\frac1{1-p}=0.469\ \text{bits}.$$

Error correction deliberately adds structured redundancy. Repetition and block codes allow a decoder to detect or correct corrupted digits. The chapter illustrates a 16-digit message expanded into a 24-digit block code: extra digits reduce transmission rate but permit reliable recovery.

> 纠错编码有意加入结构化冗余。重复码和分组码使解码器能够检测或纠正被破坏的数字。本章把一条 16 位消息扩展为 24 位分组码：额外数字降低了表面传输速率，却使可靠恢复成为可能。

> **Key point. Redundancy that is wasteful in a noiseless channel can be essential in a noisy channel.**
>
> **要点：在无噪信道中显得浪费的冗余，在有噪信道中可能是可靠通信所必需的。**

## 4.8 Capacity of a Noisy Channel / 有噪信道的容量

The most general definition of channel capacity is

> 最一般的信道容量定义为：

$$C=\max_{p(X)}I(X;Y)\ \text{bits per channel use}.$$

Using conditional entropy,

> 使用条件熵可写为：

$$C=\max_{p(X)}[H(X)-H(X\mid Y)].$$

The maximisation chooses the input distribution that makes input-output shared information as large as possible.

> 这个最大化过程选择使输入输出共享信息达到最大的输入分布。

## 4.9 Shannon's Noisy Channel Coding Theorem / 香农有噪信道编码定理

The theorem states that if information is transmitted at any rate \(R<C\), there exist sufficiently long codes for which the probability of decoding error can be made arbitrarily small. Reliable transmission above capacity is impossible.

> 该定理指出：只要信息传输速率 \(R<C\)，就存在足够长的编码，使解码错误概率可以降到任意小；超过容量的可靠传输则不可能实现。

The noisy typewriter example has nine equally probable inputs and three possible outputs for each input. Thus

> “含噪打字机”例子有九个等概率输入，每个输入对应三个可能输出。因此：

$$H(X)=\log9=3.17\ \text{bits/s},$$
$$H(Y)=\log27=4.76\ \text{bits/s},$$
$$H(Y\mid X)=\log3=1.59\ \text{bits/s},$$
$$I(X;Y)=4.76-1.59=3.17\ \text{bits/s}.$$

**Figure 4.9. The noisy typewriter maps each typed letter to one of three possible printed letters. Carefully chosen input letters can still be decoded without ambiguity.**

> **图 4.9　含噪打字机把每个输入字母映射为三个可能的打印字母之一；仔细选择输入字母后，仍可无歧义解码。**

## 4.10 Why the Theorem is True / 定理为什么成立

Long input blocks divide into a high-probability typical set. Noise spreads each codeword over a set of likely outputs, sometimes pictured as a 'noise sphere'. If codewords are selected sparsely enough that their likely output sets do not overlap, the decoder can identify the transmitted codeword. Below capacity, increasingly long blocks make overlap probability arbitrarily small; above capacity, too many codewords must share the available output space.

> 长输入块形成一个高概率典型集合。噪声把每个码字扩散到一组可能输出，常形象地称为“噪声球”。如果码字选择得足够稀疏，使它们的可能输出集合互不重叠，解码器就能识别发送的码字。低于容量时，增加块长可使重叠概率任意小；高于容量时，码字过多，必然挤占同一输出空间。

## 4.11 Summary / 小结

Joint, marginal and conditional distributions quantify a noisy channel. Mutual information is the information that survives from input to output, and noisy-channel capacity is its maximum over input distributions. Shannon's theorem proves that structured redundancy and long block codes can make error probability arbitrarily small at every rate below capacity.

> 联合分布、边缘分布和条件分布共同刻画有噪信道。互信息表示从输入保留到输出的信息，而有噪信道容量是互信息在所有输入分布上的最大值。香农定理证明，只要速率低于容量，就能利用结构化冗余和长分组码把错误概率降到任意小。
